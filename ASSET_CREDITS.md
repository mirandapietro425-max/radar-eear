# Créditos de mídia

Os assets SVG incluídos no produto são composições locais/diagramas editoriais do projeto, identificados por caminho e entidade.

Campos previstos no sistema:
- `id`
- `src`
- `alt`
- `type`
- `license`
- `author`
- `source`
- `attribution`
- `entityId`

Quando uma imagem externa é usada em uma experiência, a interface deve mostrar a fonte e o status de direitos; quando isso não puder ser comprovado, usa-se placeholder contextual ou asset próprio.
