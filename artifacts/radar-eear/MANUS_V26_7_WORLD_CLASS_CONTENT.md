# 2. DIREÇÃO DE ARTE

A Home não pode usar fotografias aleatórias.

Toda imagem deve ser semanticamente coerente com a ação.

Exemplos:

Matemática → imagem/visual de matemática.
Física → experimento/fenômeno físico.
Português → linguagem/texto/literatura.
Inglês → leitura/linguagem.
Bíblia → manuscrito/mapa/contexto bíblico.
Atlas → cartografia/local real.
Biblioteca → capa real/obra/acervo.
Pensador → retrato real ou acervo verificável.

Para cada matéria criar um pacote visual:

- 1 hero;
- 1 imagem para a página principal;
- imagens para os principais módulos;
- imagens para cards;
- recortes 16:9;
- recortes 4:5;
- recortes 1:1 quando necessário.

Não usar a mesma imagem para tudo.

Registrar no media registry:

- asset_id;
- URL;
- fonte;
- autor/instituição;
- licença;
- crédito;
- alt;
- assunto;
- uso recomendado;
- data de verificação.

Priorizar acervos institucionais, domínio público, Wikimedia Commons, NASA, Smithsonian, bibliotecas, museus, universidades e fontes com licença clara.

# 5. 500 NOVAS QUESTÕES

Criar pelo menos 500 novas questões autorais/similares, com dificuldade elevada.

Distribuição mínima:

- 125 Português;
- 125 Matemática;
- 125 Física;
- 125 Inglês.

Não chamar questões autorais/similares de oficiais.

Cada questão deve conter:

- id único;
- disciplina;
- assunto;
- subassunto;
- enunciado;
- 4 ou 5 alternativas;
- resposta;
- explicação detalhada;
- dificuldade;
- tempo estimado;
- competência/conceito;
- origem;
- evidência/fonte da habilidade cobrada;
- relações com microconceito;
- tags;
- sugestão de revisão.

Distribuir dificuldades aproximadamente entre:

- intermediária;
- difícil;
- muito difícil.

A maior parte deve exigir raciocínio, não só memorização.

# 6. COMO USAR PDFs ONLINE

Pesquisar materiais online de preparação, apostilas, manuais, aulas, documentos de universidades, órgãos públicos e materiais gratuitos.

PRINCÍPIO LEGAL:

PDF gratuito para leitura não significa automaticamente domínio público ou licença para redistribuição.

Portanto:

- baixe e incorpore o PDF ao projeto somente quando a licença permitir ou houver autorização explícita;
- quando o PDF for protegido, use-o como fonte de pesquisa para identificar conteúdos, competências e padrões;
- não copie páginas, textos ou questões protegidas literalmente para republicação;
- crie questões autorais novas baseadas nos conceitos estudados;
- registre a fonte do material usado.

Priorizar documentos com licença aberta, domínio público, Creative Commons compatível e material institucional autorizado.

Para cada PDF usado como pesquisa:

- title;
- creator;
- organization;
- year;
- URL;
- license;
- allowed_use;
- topics_extracted.

# 9. DISTRACTORS DE ALTO NÍVEL

Alternativas erradas devem representar erros plausíveis.

Evitar:

- alternativas absurdas;
- pistas gramaticais;
- resposta muito maior que as outras;
- padrão previsível;
- letra correta repetida de modo artificial.

5. erro comum;
6. microconceito relacionado;
