# Fontes de dados

## EEAR/FAB
- Portal de ingresso/SGCEM: https://ingresso.eear.fab.mil.br/
- Página oficial de provas anteriores: https://ingresso.eear.fab.mil.br/SOO/home/provas_anteriores.php?sigla_conc=%25
- Página institucional EEAR: https://www.fab.mil.br/admissao/militares-de-carreira/eear/
- O catálogo local registra edição, código, opção, estado de gabarito, URL oficial, fonte e status de direitos. Quando uma prova antiga não foi baixada, ela permanece como referência externa claramente identificada.

## Livros
- Project Gutenberg: https://www.gutenberg.org/
- Open Library: https://openlibrary.org/
- A leitura integrada usa somente edições identificadas no `BOOK_META`; obras sem licença de redistribuição permanecem como metadados + fonte legítima.

## Bíblia
- Fonte técnica de capítulos: https://api.getbible.net/v2/
- A interface identifica a fonte da edição usada; não presume licença para copiar traduções modernas protegidas.

## Ciência e experiências
- Referências externas podem ser PhET e GeoGebra quando apropriado. O Radar não copia conteúdo proprietário; usa integração/referência.
